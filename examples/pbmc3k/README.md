# Real PBMC3k results generated with R

This folder contains real outputs from the R / Seurat workflow.
The run retained 2,542 cells and 13,522 genes, and identified 9 Louvain clusters.
Cell labels remain candidates; inspect the marker plots and evidence tables.
Clusters 6 remain unresolved under the configured conservative rule.

Open report.html for the offline report or pbmc3k_walkthrough.html for
the executed R Markdown lesson. Full intermediate Seurat objects are in
the separately delivered full-results archive. Synthetic software tests
are documented in validation and are distinct from these PBMC3k results.

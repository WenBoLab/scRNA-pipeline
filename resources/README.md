# Bundled teaching resources

`pbmc3k/` contains a standard 10x sparse raw count matrix and its SHA-256
provenance. No normalized matrix or large analysis object is used as input.
`reactome_2022.gmt` is the fixed human Reactome_2022 collection from Enrichr.
`reactome_source.json` records the source URL, hash and licensing.

The default analysis runs without a data download after R packages have been
installed. See `docs/01_dataset.md` for attribution and the conversion check.
